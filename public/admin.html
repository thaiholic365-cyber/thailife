1. 조회 조건

OpenStreetMap에서 무료로 장소를 불러옵니다. (API 키 불필요 · ODbL 라이선스)

OSM은 주소 태그가 없는 장소가 많습니다. 해제한 뒤 목록에서 "📍 주소 자동 채우기"를 쓰면 좌표로 주소를 조회해 채워줍니다.
💡 사용 순서
① 조회 → ② 원하는 곳 체크 → ③ 한국어 이름 입력 → ④ JSON 내보내기 → ⑤ 관리자 페이지에서 "JSON 불러오기"

이미 등록된 곳은 좌표로 자동 대조해 중복 표시되고 기본 선택에서 제외됩니다.

📍 주소가 비어있는 경우
OSM은 주소 태그가 없는 장소가 많습니다. 목록의 주소 칸에 직접 입력하시면 그대로 저장됩니다. 구글맵 링크는 좌표 + 원어 상호명으로 생성되어 주소가 없어도 정확히 연결됩니다.

2. 선별 & 한국어 이름

체크한 항목만 내보내집니다. 한국어 이름을 비워두면 원래 이름이 그대로 사용됩니다.
